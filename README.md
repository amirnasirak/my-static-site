# Amir Khan - Personal Portfolio

A sleek, responsive, and modern personal portfolio website built to showcase my professional experience, skills, and projects as a Computer Systems Engineer and CEM Specialist. The project features a premium "glassmorphism" design aesthetic.

## 🚀 Features

- **Glassmorphism Design:** Translucent cards, deep blur effects, and animated glowing background orbs.
- **Fully Responsive:** Optimized layout for desktops, tablets, and mobile devices.
- **Smooth Scrolling:** Easy navigation across different sections (About, Skills, Projects, Contact).
- **No Dependencies:** Built entirely with raw, semantic HTML5 and custom CSS3.

## 🛠️ Tech Stack

- **HTML5:** For semantic structure and content mapping.
- **CSS3:** For styling, Flexbox/Grid layouts, animations, and backdrop-filter effects.
- **Fonts:** [Inter](https://fonts.google.com/specimen/Inter) from Google Fonts.

## 💻 Running the Project Locally

To run this project on your local machine, you need [Node.js](https://nodejs.org/) installed.

1. Clone the repository or navigate to the project folder:
   ```bash
   cd my-static-site
   ```
2. Start a local development server using `npx`:
   ```bash
   npx serve .
   ```
3. Open your browser and navigate to `http://localhost:3000`.
